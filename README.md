# 가우스 소거 실습실

**https://infgrp.github.io/gauss-elimination/**

연립일차방정식을 **행렬로 세우고**, **가우스 소거법으로 풀고**, 그 풀이가 결국
**어떤 기본행렬들의 곱**이었는지까지 한 화면에서 차례로 따라가는 수업용 도구.

파일 하나로 끝난다. 설치도 빌드도 서버도 없고, `index.html` 을 열면 그대로 돌아간다.

## 세 가지 목적

앱 맨 위에서 고른다. 고르는 것에 따라 1막과 결과 칸이 바뀐다.

| | 무엇을 |
| --- | --- |
| **연립방정식 풀기** | `Ax = b` · 식을 글로 적어 넣거나 표로 입력 |
| **기약행사다리꼴 만들기** | `A → R` · 방정식이 아니라 행렬 하나를 줄인다. 계수(rank)와 자유로운 열을 읽는다 |
| **역행렬 구하기** | `[A \| I]` → `[I \| A⁻¹]` · 교과서 방식 그대로 |

### 식을 글로 적어 넣기

`연립방정식 풀기` 에서 **식으로 입력** 을 고르면 그대로 타이핑하면 된다.

```
2x + 3y - z = 5
4x + 4y - 3z = 3
-2x + 3y - z = 1
```

- 변수 이름은 아무 글자나 된다 (`x`, `y`, `x1`, `a` …). 이름순으로 정렬해서 열을 잡는다
- 계수는 정수·분수·소수 모두 된다 — `1/2 x`, `0.25y`
- 양변 어디에 있어도 된다 — `2x + 1 = y - 3` 도 읽는다
- `Ctrl`(`⌘`) + `Enter` 로 바로 적용

## 세 막

| | 무엇을 보여 주나 |
| --- | --- |
| ① 문제 세우기 | 고른 목적에 맞게 `Ax = b` · `A` · `[A\|I]` 를 세우는 과정 |
| ② 기본행연산으로 줄이기 | 한 단계씩 소거. 각 단계를 `E · (이전) = (다음)` 등식으로 |
| ③ 기본행렬의 곱으로 | `P₁ = E₁`, `P₂ = E₂E₁`, … 누적되는 곱과 그 결론 |

3막의 마지막에서, 왼쪽 블록이 단위행렬이 되면 **그 곱이 곧 `A⁻¹`** 임을 `P·A = I` 로 확인해 준다.
역행렬 모드에서는 한 걸음 더 나아가, **오른쪽 절반이 바로 그 `P`** 임을 같은 행렬로 확인해 준다 —
`[A | I]` 로 놓고 푸는 방법이 통하는 이유가 이것이다.
거꾸로 `A = E₁⁻¹E₂⁻¹⋯Eₖ⁻¹R` 로 되돌아가는 길도 한 줄로 적어 둔다 — LU 분해로 넘어갈 때 발판이 된다.

## 문제는 매번 새로 뽑는다

고정 예제가 아니라, 누를 때마다 다른 행렬이 나온다. 다만 **답에서 거꾸로** 만든다.

1. 정수해 `x` 를 먼저 정하고
2. 단위행렬에 정수 행연산을 몇 번 걸어 계수행렬 `A` 를 만든 뒤 (행렬식이 ±1이라 소거가 깨끗하다)
3. `b = Ax` 로 우변을 얻는다

그래서 매번 달라도 답은 늘 깔끔하게 떨어진다. 성분이 너무 커지면 다시 뽑는다.

목적마다 뽑을 수 있는 갈래가 다르다.

**연립방정식 풀기**

- **유일해** — 계산도 정수로 떨어진다
- **분수가 나오게** — 한 행에 2·3을 곱해 선행성분을 1이 아니게. 중간엔 분수, 답은 정수
- **해가 무수히** — 앞 식들의 정수결합인 종속 식을 섞어 자유변수를 만든다
- **해가 없음** — 종속 식의 **우변만** 어긋나게 해서 `0 = (0 아닌 수)`

**기약행사다리꼴 만들기** — 계수가 꽉 찬 행렬 / 계수가 모자란 행렬(0인 행이 남는다)

**역행렬 구하기** — 가역 행렬 / 분수가 나오는 가역 행렬

## 수업에서 쓰기

- **단계 스크러버** — 슬라이더로 앞뒤로 감으며 설명한다. `←` `→` 키도 된다
- **직접 모드** — 학생이 행연산을 골라 적용하는 연습. 0을 곱하면 되돌릴 수 없다고 막는다
- **행사다리꼴 / 기약행사다리꼴** 을 골라서 진행
- 3막의 누적 곱 줄을 누르면 그 단계로 바로 이동한다
- 숫자를 직접 고치면 1막의 연립방정식이 바로 따라 바뀐다 — 교과서 문제를 그대로 넣어도 된다

## 계산에 대하여

모든 연산은 **유리수**로 한다. 부동소수점을 쓰지 않으므로 `1/3` 이 `0.3333` 으로 새지 않고,
분수는 세로쌓기로 그린다. `3`, `-1/2`, `0.25` 는 모두 같은 방식으로 읽어 들인다.

추축을 고를 때는 그 열에서 `|분자| + |분모|` 가 가장 작은 행을 쓴다.
1 이나 −1 이 있으면 그것을 골라 분수가 덜 생기게 하려는 것이다.
행사다리꼴은 **선행성분을 1로 맞추는** 우리 교과서 정의를 따른다.

- 색 — 파일 맨 위 `:root` 의 토큰. `--pivot`(선행성분)과 `--change`(방금 바뀐 행)는
  뜻이 정해진 색이라 UI 강조색 `--accent` 와 따로 두었다
- 밝은/어두운 테마는 토큰만 다시 정의한다
