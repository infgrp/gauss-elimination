# 선형대수 실습실

**https://infgrp.github.io/gauss-elimination/**

행렬 계산을 **답만이 아니라 과정째** 보여 주는 수업용 도구.
연립일차방정식을 가우스 소거로 풀고 그 풀이가 **어떤 기본행렬들의 곱**이었는지 되짚는 데서 시작해,
역행렬, **대각화와 거듭제곱**, 대칭행렬의 **직교대각화**, 어떤 행렬에나 통하는 **특이값 분해(SVD)** 까지
같은 방식으로 따라간다.

(처음 이름은 "가우스 소거 실습실"이었다. 기존 링크가 깨지지 않도록 저장소 이름과 주소는 그대로 둔다.)

파일 하나로 끝난다. 설치도 빌드도 서버도 없고, `index.html` 을 열면 그대로 돌아간다.

## 여섯 가지 목적

앱 맨 위에서 고른다. 고르는 것에 따라 1막과 결과 칸이 바뀐다.

| | 무엇을 |
| --- | --- |
| **연립방정식 풀기** | `Ax = b` · 식을 글로 적어 넣거나 표로 입력 |
| **기약행사다리꼴 만들기** | `A → R` · 방정식이 아니라 행렬 하나를 줄인다. 계수(rank)와 자유로운 열을 읽는다 |
| **역행렬 구하기** | `[A \| I]` → `[I \| A⁻¹]` · 교과서 방식 그대로 |
| **대각화와 거듭제곱** | `A = PDP⁻¹` → `Aᵏ = PDᵏP⁻¹` |
| **직교대각화** | 대칭행렬 `A = QDQᵀ` · 스펙트럼 분해 |
| **특이값 분해 (SVD)** | 모든 `m × n` 행렬 `A = UΣVᵀ` · 랭크 1 합과 최선의 근사 |

아래 세 목적에서는 2막·3막이 소거 대신 고유값 쪽 내용으로 바뀐다.

주소 뒤에 `?p=diag` 를 붙이면 처음부터 그 화면으로 열린다
(`?p=rref`, `?p=inverse`, `?p=orth`, `?p=svd` 도 된다). 수업 자료에 바로 걸 링크로 쓴다.

## 대각화와 거듭제곱

2 × 2 ~ 4 × 4 정사각행렬을 다룬다.

| | 무엇을 보여 주나 |
| --- | --- |
| ① 문제 세우기 | `Av = λv` → `AP = PD` → `A = PDP⁻¹` → `Aᵏ = PDᵏP⁻¹` 로 이어지는 생각의 순서 |
| ② 고유값과 고유벡터 | `det(A − λI)` 를 행렬째 보여 주고 전개·인수분해. 고유값마다 `A − λI` 를 **이 앱의 소거로** 기약행사다리꼴까지 줄이고(행연산 목록은 펼쳐 볼 수 있다), 자유변수에서 고유벡터를 읽는다. 중근인데 고유벡터가 모자라면 빨간 글씨로 짚는다 |
| ③ 대각화와 거듭제곱 | `P`, `D`, `P⁻¹`(`[P \| I]` 를 줄여서) → `PDP⁻¹ = A`, `P⁻¹AP = D` 검산 → `k` 를 슬라이더로 바꾸며 `P · Dᵏ · P⁻¹ = Aᵏ`. 직접 `k − 1` 번 곱한 값과 같은지 확인하고, 모든 `k` 에 대한 **일반항** `Aᵏ = Σ λᵏ · (고정된 행렬)` 도 적어 준다 |

- 특성다항식은 파데예프–르베리에 방법으로 분수 그대로 구하고, 고유값은 **유리근 정리**로 찾는다.
  유리수가 아닌 고유값이 섞이면(예: 회전행렬, `[[1,1],[1,0]]`) 대각화는 하지 않고,
  남은 2차식이면 무리수인지 복소수인지와 그 근을 적어 준다. 거듭제곱은 이때도 직접 곱해서 보여 준다
- `Aᵏ` 는 `BigInt` 분수로 계산해 `k = 200` 까지 정확하다
- 문제 갈래: **서로 다른 고유값** / **P⁻¹ 에 분수** / **중근인데 대각화됨**(3 × 3 이상) / **대각화 불가능**.
  다른 목적과 마찬가지로 답(P와 고유값)을 먼저 정하고 `A = PJP⁻¹` 로 거꾸로 만들어, 고유값이 늘 정수로 떨어진다

### 식을 글로 적어 넣기

`연립방정식 풀기` 에서 **식으로 입력** 을 고르면 그대로 타이핑하면 된다.

```
2x + 3y - z = 5
4x + 4y - 3z = 3
-2x + 3y - z = 1
```

- 변수 이름은 아무 글자나 된다 (`x`, `y`, `x1`, `a` …). 이름순으로 정렬해서 열을 잡는다
- 계수는 정수·분수·소수 모두 된다 — `1/2 x`, `0.25y`
- 양변 어디에 있어도 된다 — `2x + 1 = y - 3` 도 읽는다
- `Ctrl`(`⌘`) + `Enter` 로 바로 적용

## 직교대각화

2 × 2 ~ 4 × 4 대칭행렬. 대칭이 아닌 행렬을 넣으면 그 자리에서 알려 준다.

| | 무엇을 보여 주나 |
| --- | --- |
| ① 문제 세우기 | `Aᵀ = A` 확인 → `A = QDQᵀ`(Q⁻¹ = Qᵀ) → 스펙트럼 분해 |
| ② 고유값과 고유벡터 | 대각화와 같은 화면 (특성방정식 → 고유값마다 소거) |
| ③ 직교대각화 | 서로 다른 고유값의 고유벡터끼리 내적이 0 임을 보이고, 겹친 고유값의 고유벡터는 **그람–슈미트**로 고친다(전·후 비교) → `qᵢ = wᵢ / √(wᵢ·wᵢ)` 로 Q → `QDQᵀ = A` 검산 → `A = Σ λ · (정사영 행렬)` |

문제 갈래: 서로 다른 고유값 / 중근 (그람–슈미트가 실제로 필요한 것만 뽑는다) / 무리수 고유값.

## 특이값 분해

`m × n` (각 2 ~ 4) 아무 행렬. 행과 열 수를 따로 고른다.

| | 무엇을 보여 주나 |
| --- | --- |
| ① 문제 세우기 | `A = UΣVᵀ` 의 뜻 (`Avᵢ = σᵢuᵢ`), V 와 σ 를 `AᵀA` 에서 얻는 이유 |
| ② AᵀA 와 특이값 | `Aᵀ · A = AᵀA` → 특성방정식·고유벡터(소거) → `σᵢ = √λᵢ`(예: `√72 = 6√2`) → V |
| ③ 특이값 분해 | `uᵢ = Avᵢ / σᵢ`, 모자라면 `Aᵀu = 0` 의 해로 U 를 채움 → `U · Σ · Vᵀ = A` 검산 → `A = σ₁u₁v₁ᵀ + ⋯` 랭크 1 행렬의 합 → 첫 항만 남긴 **최선의 랭크 1 근사**와 그 오차(%) — 사진 압축으로 이어지는 대목 |

문제 갈래: 특이값이 깔끔하게 / 랭크가 모자란 행렬 / 무리수 특이값.

### 정확한 값과 소수 근사

- 고유값이 유리수이면 **정확하게** 적는다. 고유벡터는 정수 벡터 `w` 로 두고 `q = w / √(w·w)` 로만 표시하므로
  `1/√2`, `2/√6`, `σ = 3√5` 처럼 교과서 꼴이 그대로 나오고, `QDQᵀ = A`, `UΣVᵀ = A` 검산은
  `Σ λ wwᵀ / (w·w)` 꼴의 분수 계산으로 끝난다 (√ 가 곱해져 사라진다)
- 고유값이 무리수이면(예: `[[2,1],[0,1]]` 의 σ ≈ 2.2882, 0.874) **야코비 회전**으로 소수 넷째 자리까지 근사하고,
  복원 오차를 함께 보여 준다
- 문제 생성은 이번에도 답에서 거꾸로: 서로 직교하는 정수 벡터를 먼저 만들고
  `A = Σ cᵢ aᵢbᵢᵀ` (SVD) / `A = Σ λᵢ wᵢwᵢᵀ / |wᵢ|²` (직교대각화) 로 정수 행렬을 얻는다

## 세 막 (연립방정식 · 기약행사다리꼴 · 역행렬)

| | 무엇을 보여 주나 |
| --- | --- |
| ① 문제 세우기 | 고른 목적에 맞게 `Ax = b` · `A` · `[A\|I]` 를 세우는 과정 |
| ② 기본행연산으로 줄이기 | 한 단계씩 소거. 각 단계를 `E · (이전) = (다음)` 등식으로 |
| ③ 기본행렬의 곱으로 | `P₁ = E₁`, `P₂ = E₂E₁`, … 누적되는 곱과 그 결론 |

3막의 마지막에서, 왼쪽 블록이 단위행렬이 되면 **그 곱이 곧 `A⁻¹`** 임을 `P·A = I` 로 확인해 준다.
역행렬 모드에서는 한 걸음 더 나아가, **오른쪽 절반이 바로 그 `P`** 임을 같은 행렬로 확인해 준다 —
`[A | I]` 로 놓고 푸는 방법이 통하는 이유가 이것이다.
거꾸로 `A = E₁⁻¹E₂⁻¹⋯Eₖ⁻¹R` 로 되돌아가는 길도 한 줄로 적어 둔다 — LU 분해로 넘어갈 때 발판이 된다.

## 문제는 매번 새로 뽑는다

고정 예제가 아니라, 누를 때마다 다른 행렬이 나온다. 다만 **답에서 거꾸로** 만든다.

1. 정수해 `x` 를 먼저 정하고
2. 단위행렬에 정수 행연산을 몇 번 걸어 계수행렬 `A` 를 만든 뒤 (행렬식이 ±1이라 소거가 깨끗하다)
3. `b = Ax` 로 우변을 얻는다

그래서 매번 달라도 답은 늘 깔끔하게 떨어진다. 성분이 너무 커지면 다시 뽑는다.

목적마다 뽑을 수 있는 갈래가 다르다.

**연립방정식 풀기**

- **유일해** — 계산도 정수로 떨어진다
- **분수가 나오게** — 한 행에 2·3을 곱해 선행성분을 1이 아니게. 중간엔 분수, 답은 정수
- **해가 무수히** — 앞 식들의 정수결합인 종속 식을 섞어 자유변수를 만든다
- **해가 없음** — 종속 식의 **우변만** 어긋나게 해서 `0 = (0 아닌 수)`

**기약행사다리꼴 만들기** — 계수가 꽉 찬 행렬 / 계수가 모자란 행렬(0인 행이 남는다)

**역행렬 구하기** — 가역 행렬 / 분수가 나오는 가역 행렬

## 수업에서 쓰기

- **단계 스크러버** — 슬라이더로 앞뒤로 감으며 설명한다. `←` `→` 키도 된다
- **직접 모드** — 학생이 행연산을 골라 적용하는 연습. 0을 곱하면 되돌릴 수 없다고 막는다
- **행사다리꼴 / 기약행사다리꼴** 을 골라서 진행
- 3막의 누적 곱 줄을 누르면 그 단계로 바로 이동한다
- 숫자를 직접 고치면 1막의 연립방정식이 바로 따라 바뀐다 — 교과서 문제를 그대로 넣어도 된다

## 계산에 대하여

모든 연산은 **유리수**로 한다. 부동소수점을 쓰지 않으므로 `1/3` 이 `0.3333` 으로 새지 않고,
분수는 세로쌓기로 그린다. `3`, `-1/2`, `0.25` 는 모두 같은 방식으로 읽어 들인다.

추축을 고를 때는 그 열에서 `|분자| + |분모|` 가 가장 작은 행을 쓴다.
1 이나 −1 이 있으면 그것을 골라 분수가 덜 생기게 하려는 것이다.
행사다리꼴은 **선행성분을 1로 맞추는** 우리 교과서 정의를 따른다.
